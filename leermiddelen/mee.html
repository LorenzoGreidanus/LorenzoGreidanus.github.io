Vul de code van het bord in

De code staat op het digibord. Zodra je hem invult, ga je naar het spel dat je docent heeft geopend.

Geen echte naam nodig. Je bijnaam staat alleen op het bord van je klas.

Werkt de code niet? Kijk of je hem goed hebt overgenomen, en of je docent het bord al heeft geopend. Een code is vier letters en blijft hoogstens een paar uur geldig.
